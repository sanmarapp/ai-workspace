# Real Estate Automation (Bangladesh)

## Purpose
Automate real estate project workflows including:
- Project approval tracking
- Document generation
- Regulatory compliance monitoring
- Timeline management

## Structure
- **approvals/** - RAJUK/BNBC approval tracking
- **documents/** - Project docs, contracts, permits
- **workflows/** - Automation scripts
- **data/** - Project data, contacts, timelines
- **scripts/** - Utility scripts

## Tools
- Google Drive integration for document storage
- Scheduled tasks for deadline reminders
- Browser automation for form submissions
